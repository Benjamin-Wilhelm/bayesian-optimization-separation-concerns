\section{Experimental reproducibility}
\label{app:exp}

This appendix records the methodological choices actually used in the
report-relevant runs. We describe the \emph{principle} of each experiment, its
benchmarks, its reproducibility conventions and its parameters, without
low-level implementation detail.

\subsection{Global conventions}

All three experiments share: a paired design (within a seed, the Sobol initial
design is drawn once and passed identically to every compared method, which
validates the paired Wilcoxon test); evaluation on the \emph{noiseless} benchmark
value (never on the noisy observation the GP trained on); input normalization to
the unit cube and output standardization, both refit at every iteration; and
Mat\'ern-$5/2$ ARD kernels with BoTorch default Gamma hyperpriors, with
hyperparameters refit from scratch by exact marginal likelihood at every BO
iteration. Regret is a loss (lower is better) reaching $0$ at the optimum. Runs
are noiseless ($\sigma=0$); Experiments A/B build a fixed-noise GP with variance
floored to $10^{-6}$, whereas Experiment~C uses an inferred-noise
\texttt{SingleTaskGP}. Statistics use the median across seeds; A/B use $95\%$
pointwise bootstrap bands ($10\,000$ resamples over seeds), C uses $25$--$75$
inter-seed percentile bands. Implementation is in BoTorch~\cite{balandat2020botorch}.

$\abs{y-T}$; both analytic sequential UCB-type acquisitions

  \item[Analysis] paired one-sided Wilcoxon (\RIGHT{} vs \WRONG),
        Mann--Whitney~$U$, rank-biserial, Cohen's~$d$.
\end{description}


\subsection{Experiment B --- prior-guided optimization}

Problem: single-objective maximization of the oriented objective with a spatial
prior; the question is where the prior enters (Section~\ref{sec:contrib-prior-exp}).
Prior bump $\pi_c(x)=\exp(-\tfrac12\sum_j((x_j-c_j)/\ell_j)^2)$. Methods:
\texttt{vanilla\_ucb}; \texttt{alpha\_pi\_ucb} (\RIGHT, prior in the exploration
bonus, $\alpha$ fixed); \texttt{lambda\_pi\_fixed\_standardized\_ucb} (\WRONG,
prior as GP mean, $\lambda=1$); \texttt{lambda\_pi\_adaptive\_standardized\_ucb}
(\WRONG, $\lambda$ learned by MLL, refit each iteration).

\subsection{Experiment C --- multi-objective optimization}

Bi-objective ($m=2$) scalarization comparing where the scalarization is applied
(Section~\ref{sec:contrib-mo-exp}). Benchmarks \texttt{zdt1} (convex front) and
\texttt{zdt2} (concave, non-supported region), $d\in\{2,6\}$. Oriented
maximization $F=-f_{\mathrm{raw}}$; fixed reference $z=(-1.1,-1.1)$; exact 2-D
hypervolume. Two scalarizations, \texttt{linear} and \texttt{hypervolume}. Two
modes: \emph{fixed} (independent scalarized runs over an angle grid
$\theta\in\{10,30,45,60,80\}^\circ$) and \emph{pareto} (global budget $500$,
hypervolume only, shared resampled-preference algorithm vs independent subruns;
$2048$ evaluation preferences from an independent shared RNG).

        no paired test in the pareto pipeline; bootstrap not used in
        Experiment~C.
\end{description}
